PREVIEW:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in your browser (or use the VS Code Live Server extension).

PUBLISH FREE FOR HIS PHONE:
1. Sign in/create an account at https://github.com/
2. Create a public repository named sriram-birthday.
3. Upload index.html and the entire media folder, preserving its filenames.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published URL to appear and send it to Sriram on WhatsApp.

Important: Keep index.html and the media folder together. Do not rename the files in media unless you also update their paths in index.html. The video is included as feeding-memory.mp4.
